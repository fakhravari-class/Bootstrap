# دورهٔ جامع آموزش Bootstrap 6

این مخزن یک مسیر آموزشی پروژه‌محور برای ساخت رابط فروشگاهی با Bootstrap، HTML و JavaScript است. نمونه‌های تمرین در هر جلسه یک موقعیت واقعی از فروشگاه ساده را نشان می‌دهند؛ مثل انتخاب ویژگی کالا، افزودن به سبد، پیگیری سفارش و چیدمان صفحه در موبایل.

در پوشهٔ هر جلسه، PDF همان جلسه و پوشهٔ «تمرین» قرار دارد. فایل‌های HTML داخل پوشهٔ تمرین را با مرورگر باز کنید. برای بارگذاری Bootstrap از CDN و نمایش تصاویر بیرونی، اتصال اینترنت لازم است.

## نسخه و سازگاری

نمونه‌ها بر اساس مستندات Bootstrap 6 نوشته شده‌اند. مستندات و CDN رسمی فعلی نسخهٔ 6.0.0-alpha.1 را نشان می‌دهند؛ این نسخه پیش‌انتشار است و ممکن است API آن تغییر کند. برای پروژهٔ واقعی، وضعیت انتشار و راهنمای مهاجرت را پیش از تثبیت وابستگی بررسی کنید.

صفحه‌های فارسی از lang="fa" و dir="rtl" استفاده می‌کنند. در Bootstrap 6 پشتیبانی RTL بر پایهٔ ویژگی‌های منطقی CSS انجام می‌شود و به فایل CSS جداگانهٔ RTL نیاز ندارد.
